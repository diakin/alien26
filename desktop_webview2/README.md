# Aliens26 — настольная оболочка на WebView2 (Lazarus + WebView4Delphi)

Второй вариант оболочки (первый, на CEF, — `tools/desktop`). Браузер не кладётся
рядом с программой: используется Microsoft Edge WebView2 Runtime, установленный
в системе. Рядом с exe нужна только папка `game` (или exe внутри репозитория).

## Windows 7

WebView2 Runtime 109 (последняя сборка 109.0.1518.140) — последняя версия,
которая работает на Windows 7. По движку это тот же Chromium 109, что и в
CEF-варианте.

- Установлен ли рантайм, видно в «Программах и компонентах»:
  «Microsoft Edge WebView2 Runtime».
- По данным Microsoft, онлайн-установщик Evergreen на Windows 7 ставит версию 109.
- Если рантайм не установлен в систему, можно указать папку Fixed Version Runtime
  параметром `/runtime=папка`. Разрядность Fixed Version Runtime должна совпадать
  с разрядностью exe.

## Что нужно для сборки

- Lazarus 2.2.x или новее (FPC 3.2.2).
- WebView4Delphi лежит в проекте: `WebView4Delphi\source` (коммит 12b0c13,
  WebView2 NuGet 1.0.4370.26, https://github.com/salvadordf/WebView4Delphi,
  лицензия MIT, файл `WebView4Delphi\LICENSE`). Пакет в Lazarus устанавливать
  не нужно: .lpi не ссылается на пакет WebView4Delphi, путь к модулям задан в
  параметрах проекта (Other unit files и Include files = `WebView4Delphi\source`).
  Компоненты TWVBrowser и TWVWindowParent создаются из .lfm и без пакета;
  без пакета не открывается только дизайнер формы uMainWV.lfm (IDE не знает
  эти классы); сборка через lazbuild и «Запуск → Собрать» работает.

## Сборка и запуск

Открыть `desktop_webview2\Aliens26WV.lpi`, Запуск → Собрать.
Exe появится в `desktop_webview2\dist\` и сам найдёт `game\globe.html`
(рядом с exe или в родительских папках до пяти уровней вверх).

Для переноса на другой компьютер:

```
Aliens26\
  Aliens26WV.exe
  game\...        (копия папки game из репозитория)
  userdata\       (создаётся при первом запуске)
```

## Загрузчик WebView2

По умолчанию используется встроенный загрузчик WebView4Delphi
(`UseInternalLoader`, основан на OpenWebView2Loader) — WebView2Loader.dll не нужна.
Причина: Microsoft не поддерживает Windows 7 в SDK начиная с 1.0.1519, а в комплекте
WebView4Delphi лежит DLL из более нового SDK. При проблемах на Windows 7 автор
WebView4Delphi советует включать встроенный загрузчик.

Если со встроенным загрузчиком что-то не так, запустите с `/dllloader` и положите
рядом с exe `WebView2Loader.dll` нужной разрядности (из `bin32` или `bin64`
репозитория WebView4Delphi).

## Управление и параметры

| Клавиша | Действие |
|---|---|
| F11 | полноэкранный режим |
| F5 / Ctrl+F5 | перезагрузить страницу / без кэша |
| F12 | инструменты разработчика |
| Esc | передаётся игре, окно не закрывает |

Полноэкранный режим из настроек игры (Fullscreen API) тоже работает.
Стандартное контекстное меню браузера и масштаб по Ctrl+колесо отключены.

```
Aliens26WV.exe [страница.html] [/fullscreen] [/nogpu] [/dllloader] [/runtime=папка]
```

- `страница.html` — стартовая страница из папки `game` (по умолчанию `globe.html`);
- `/fullscreen` — запуск сразу во весь экран;
- `/nogpu` — без аппаратного ускорения (чёрный экран, мерцание);
- `/dllloader` — WebView2Loader.dll вместо встроенного загрузчика;
- `/runtime=папка` — Fixed Version Runtime из указанной папки.

Если WebView2 не запустился, программа покажет сообщение об ошибке и
найденную версию рантайма.

## Сохранения

localStorage хранится в `userdata\` рядом с exe. Это отдельный профиль:
сохранения из обычного браузера и из CEF-варианта сюда не переносятся.
Папка должна быть доступна на запись.

## Состояние проверки

Проект собран кросс-компиляцией под win64 (Lazarus 3.0, FPC 3.2.2, WebView4Delphi
1.0.4370.26) без ошибок. Запуск не проверялся — ни на Windows 10, ни на
Windows 7 с рантаймом 109. WebView4Delphi рассчитан на рантаймы новее 109;
в проекте включён `AllowOldRuntime`, но работу с 109 нужно проверить на месте.
