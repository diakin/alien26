# Люди для спрайтов и портретов (MakeHuman)

`human.js` строит гражданских и персонал базы на основе базовой сетки MakeHuman.
Данные в этой папке генерируются скриптом и в репозиторий не входят (кроме параметров тел `bodies/*.mhm`).

## Источники (CC0)

- makehumancommunity/makehuman — базовая сетка hm08, морф-цели (macrodetails, измерения, руки и ноги, корпус, лицо), глаза (high-poly proxy).
- makehumancommunity/mpfb2 — скелет game_engine (53 кости) и веса кожи `weights.game_engine.json`.

Лицензия ассетов обоих проектов — CC0 (см. LICENSE.ASSETS.md в makehuman).

## Генерация

```
git clone --depth 1 https://github.com/makehumancommunity/makehuman ext/makehuman
git clone --depth 1 https://github.com/makehumancommunity/mpfb2 ext/mpfb2
python3 mhbuild.py ext/makehuman/makehuman/data ext/mpfb2/src/mpfb/data
```

Скрипт пишет `topology.json` (общая топология, части сетки, веса, кости), `kind_<вид>.json`
(форма тела и лица, суставы) и `skin_<вид>.png` (текстура кожи 2048², брови, щетина, губы) для 21 вида,
а также `eye_brown.png`. Список видов и параметры (пол, возраст, телосложение, цвет кожи и волос) — `KINDS` в `mhbuild.py`.

## Параметры тела: MakeHuman и `bodies/<вид>.mhm`

Форма тела каждого вида задаётся файлом `bodies/<вид>.mhm` — это файл модели MakeHuman. Если файла нет, берутся
параметры из `KINDS` в `mhbuild.py` (пол, возраст, мышцы, вес, `slim` — общая худоба, `shape` — отдельные морфы).

Правка в MakeHuman (бесплатно, открытый код; версия 1.2 — Windows 64-бит):

1. Скачать MakeHuman 1.2 с makehumancommunity.org, запустить.
2. Файлы → Загрузить → выбрать `bodies/<вид>.mhm` (папку указать кнопкой «...»).
3. Двигать ползунки: «Основное» (пол, возраст, мышцы, вес, рост, пропорции), «Торс», «Руки и ноги»,
   «Измерения» (ширина плеч, обхваты груди, талии, бёдер, плеча, бедра, икры и др.). Лицо можно не трогать.
4. Файлы → Сохранить → тем же именем `<вид>.mhm` в ту же папку.
5. Пересобрать: `ONLY=<вид> python3 mhbuild.py`, затем спрайты.

Что берётся из файла: пол, возраст, мышцы, вес, рост, пропорции, доли рас и все модификаторы формы
(«группа/морф» — измерения, корпус, руки и ноги, бёдра, живот, ягодицы и т. д.). Черты лица — из файла, если в нём
есть модификаторы лица; иначе случайные по `seed` вида. Цвет кожи и волос, одежда — из `KINDS` и `civilian.js`
(одежда, глаза, поза и прочие строки файла MakeHuman не читаются).

Значения ползунков в MakeHuman — от −1 до 1; значение за этими пределами (можно записать в файл вручную)
сборка применит как есть, а MakeHuman при загрузке ограничит до ±1.

`EXPORT_MHM=<вид>,<вид> python3 mhbuild.py` — записать `bodies/<вид>.mhm` из `KINDS` (существующий файл не перезаписывается).
